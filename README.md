# مراقب مقاعد MedSky ✈️

سكريبت يفحص توفر المقاعد على رحلات MedSky كل نص ساعة، ويبعثلك رسالة تيليغرام
أول ما رحلة كانت Sold Out يرجعلها مقاعد.

المسار الحالي: **معيتيقة (MJI) ← ميلانو (MXP)** — تبدله من ملف
`.github/workflows/monitor.yml` (المتغيرين `MEDSKY_FROM` و `MEDSKY_TO`).

---

## الإعداد (مرة وحدة، ~15 دقيقة)

### 1) بوت تيليغرام
1. افتح تيليغرام وكلم **@BotFather**
2. ابعثله `/newbot` وامشي مع التعليمات (اختار أي اسم)
3. بيعطيك **توكن** شكله: `123456789:AAH...` — احتفظ بيه
4. **مهم:** افتح محادثة مع البوت الجديد متاعك واضغط Start
5. باش تجيب **chat id** متاعك: كلم **@userinfobot** وبيرد عليك برقمك (Id)

### 2) GitHub
1. اعمل حساب على github.com لو ما عندكش
2. اعمل **Repository جديد** — اختار **Private** (باش محد يشوف إعداداتك)
3. ارفع الملفات الثلاثة بنفس التركيبة:
   - `monitor.py`
   - `README.md`
   - `.github/workflows/monitor.yml` ← لازم بالضبط في هذا المسار
4. من صفحة الريبو: **Settings ← Secrets and variables ← Actions ← New repository secret**
   وأضف اثنين:
   - الاسم: `TELEGRAM_BOT_TOKEN` والقيمة: التوكن من BotFather
   - الاسم: `TELEGRAM_CHAT_ID` والقيمة: رقمك من userinfobot

### 3) تجربة أول تشغيل
1. من صفحة الريبو: تبويب **Actions**
2. لو طلبلك تفعيل الـ workflows، فعّلهم
3. اختار **MedSky seat monitor** من القائمة على اليسار ← زر **Run workflow**
4. استنى دقيقة وافتح نتيجة التشغيل — المفروض تشوف قائمة الرحلات وعدد المقاعد
5. أول تشغيل **ما يبعثش تنبيه** حتى لو في مقاعد — يسجل الوضع الحالي بس.
   التنبيهات تبدا من التشغيل الثاني، وبس كي رحلة تتحول من 0 لمقاعد متوفرة.

خلاص — من هنا وطالع يشتغل وحده كل نص ساعة.

---

## تخصيص

كل الإعدادات في `monitor.yml`:

| المتغير | معناه | الافتراضي |
|---|---|---|
| `MEDSKY_FROM` / `MEDSKY_TO` | كود المطارين | MJI / MXP |
| `MEDSKY_CLASSES` | الفئات اللي تحسب "مقعد متاح" | `Y,R` (السياحية) — زيد `C` لو البيزنس يهمك |
| `MEDSKY_MAX_DAYS` | تنبيه بس للرحلات خلال X يوم | معطّل |

باش تراقب **خطين** (مثلاً الذهاب والإياب): اعمل نسخة ثانية من `monitor.yml`
باسم مختلف وبدّل فيها `MEDSKY_FROM`/`MEDSKY_TO`، وبدّل في `monitor.py`
اسم ملف الحالة أو الأبسط: اعمل ريبو ثاني.

## ملاحظات

- GitHub Actions المجاني ممكن يأخر التشغيل شوي وقت الزحمة (يوصل لساعة
  بدل نص ساعة) — مقبول لهذا الاستعمال.
- لو التشغيل فشل برسالة **403** أو **401**: السيرفر بدا يطلب معرف جلسة.
  ارجع للمحادثة مع Claude بالخطأ ونعدلوا السكريبت.
- السكريبت يبعث طلب واحد كل نص ساعة — حمل أقل بكثير من مستخدم عادي
  يقلب في الموقع، فما فيش إزعاج للسيرفر.
